The Personal Health Tracker and Reminder System is a console-based C++ application designed to help users record, store, and manage their personal health information. In today’s busy life, people often forget to monitor their health regularly. This system provides a simple and effective way to keep track of health data and reminds users about healthy practices.
Functional Requirements
1.	The system shall allow the user to add health data
2.	The system shall store data in a text file
3.	The system shall display saved health records
4.	The system shall show reminder messages
5.	The system shall allow exit from the program safely
